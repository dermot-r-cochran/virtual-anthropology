# virtual-anthropology
## The Archipelago

This repository contains [The Archipelago](the-archipelago/README.md), a deterministic, event-sourced virtual civilization and Virtual Anthropology research platform. It includes an Evennia world layer and publishes to a GitHub Pages site.

## Related

- [world-model](https://github.com/dermot-r-cochran/world-model) is the nearest in subject on the state side: governed state whose every change is an auditable event. Independent code.
